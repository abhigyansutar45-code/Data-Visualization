
# 🌍 Country GDP Data Visualization

A Python project that visualizes and compares the GDP (Gross Domestic Product) of different countries using charts and graphs.

## 📊 Dashboard Preview

![Country GDP Data Visualization](images/country_gdp_dashboard.png)

## 📌 Project Overview

This project includes four types of data visualizations:

- 📊 Bar Chart — Compare GDP across countries.
- 📈 Line Chart — Show GDP differences between countries.
- 🥧 Pie Chart — Display each country's share of total GDP.
- 📉 Column Chart — Compare GDP using vertical bars.
